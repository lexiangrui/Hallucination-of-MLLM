# 误差分析实验设计

## 1. 实验总览

在完成主实验（POPE/MathVista/VQA-RAD）和人类对齐验证之后，本节通过四个专项误差分析实验，从不同角度检验评估方法的可靠性、揭示系统性偏差并分析幻觉的本质模式。

| 编号 | 实验 | 原理 | 所需资源 |
|------|------|------|---------|
| E1 | Judge 模型一致性检验 | 测量工具可靠性 | 100 条 × Claude Opus API |
| E2 | 幻觉判定阈值敏感性分析 | 指标稳定性 | 零成本，使用已有数据 |
| E3 | 评分者长度偏差分析 | Judge 系统性偏差 | 零成本 |
| E4 | 跨模型幻觉一致性分析 | 幻觉模式分析 | 零成本 |

---

## 2. 实验一：Judge 模型一致性检验

### 2.1 原理

在 LLM-as-a-Judge 范式中，评估模型本身就是一个大语言模型，其自身的偏好和偏差可能影响评估结果。多项研究发现，不同 LLM Judge 之间存在系统性差异（Zheng et al., 2023; Dubois et al., 2024）。本实验通过对比 GPT-5.5 Judge 和 Claude Opus 4.7 Judge 在同一批样本上的评估结果，检验我们的幻觉检测结论是否依赖于 Judge 模型的选择。

### 2.2 方法

**样本选择**：从 MathVista testmini 中随机抽取 100 条样本（seed=42），覆盖 4 个模型的 Direct 模式回答。每个模型各 100 条回答被同一批 Judge 评估。

**Judge 配置**：Claude Opus 4.7，temperature=0.0，使用与 GPT-5.5 Judge 完全相同的 system prompt（MMHal-Bench 0-6 评分的完整 System Prompt，含 same few-shot 示例和幻觉类型分类）。

**对比指标**：

| 指标 | 说明 |
|------|------|
| Hallucination Rate | 两个 Judge 的 HR 逐模型对比 |
| Average Score | 两 Judge 的平均分对比 |
| Pearson r | 两 Judge 在逐样本 score 上的线性相关性 |
| Cohen's Kappa | 两 Judge 在二分类（含/不含幻觉）上的一致性 |
| 排名一致性 | 两 Judge 对 4 个模型的性能排名是否一致 |

### 2.3 参考文献

1. Zheng et al., "Judging LLM-as-a-Judge with MT-Bench: A Comprehensive Study of LLM-as-a-Judge for Chatbot Evaluation", 2023.
2. Dubois et al., "Length-Controlled AlpacaEval: A Simple Way to Debias Automatic Evaluators", 2024.

## 3. 实验二：幻觉判定阈值敏感性分析

### 3.1 原理

Hallucination Rate 的核心计算方式为 $HR = N_{score < T} / N_{total}$，其中 $T=3$ 为固定的幻觉判定阈值。该阈值的选择参考了 MMHal-Bench（Sun et al., 2024）的评分协议。但如果阈值小幅变动导致模型相对排名发生显著变化，则说明该指标对阈值敏感，结论的稳健性需要审慎讨论。

### 3.2 方法

对所有模型的全部可用结果（4 模型 × 6 数据集 = 24 个结果文件），依次将阈值 T 从 0 遍历至 6，计算每个 T 下的 HR：

$$HR(T) = \frac{N_{score < T}}{N_{total}}, \quad T \in \{0, 1, 2, 3, 4, 5, 6\}$$

**输出**：

- 每个 (model, dataset) 的 HR-T 曲线
- 每个模型在不同数据集上的 HR-T 曲线叠图
- 在 T=2、T=3、T=4 时各模型的排名表，观察排名是否稳定

### 3.3 参考文献

Sun et al., "Aligning Large Multimodal Models with Factually Augmented RLHF", ACL Findings 2024. (MMHal-Bench 协议)

## 4. 实验三：评分者长度偏差分析

### 4.1 原理

LLM-as-a-Judge 的"长度偏差"（Length Bias）已被多篇研究确认为系统性偏差（Zheng et al., 2023; Dubois et al., 2024）：Judge 倾向于给更长、更详细的回答打更高分，即使内容质量相同。我们的实验场景中，CoT 模式的回答（中位词数 43-228）远长于 Direct 模式（中位词数 1-242），如果 Judge 存在长度偏差，CoT 模式的评分可能会被系统性抬高或压低，从而影响 CoT 效果的结论。

### 4.2 方法

**全样本分析**：对 MathVista Direct 和 CoT 的全部 1000 条样本，计算每条约答的词数 len(answer) 与 Judge score 之间的 Spearman 相关系数 $\rho$。分别计算 4 个模型 × 2 种模式 = 8 个相关系数。

**混淆因素控制**：回答长度与答案正确性相关。更长的答案往往包含更多推理，可能确实质量更高。为分离"长度本身"和"质量提升"的影响，在控制 answer_is_correct（是否与 GT 匹配）变量后，计算偏相关系数 $r_{(len, score | correct)}$。

**跨模式比较**：对每条约答，计算其 CoT 模式与 Direct 模式的 $\Delta len$ 和 $\Delta score$，分析两者是否相关。如果存在长度偏差，$\Delta len$ 应与 $\Delta score$ 正相关。

### 4.3 参考文献

1. Zheng et al., "Judging LLM-as-a-Judge with MT-Bench", 2023.
2. Dubois et al., "Length-Controlled AlpacaEval: A Simple Way to Debias Automatic Evaluators", 2024.
3. Saito et al., "Length Bias in Large Language Model Evaluators", 2024.

## 5. 实验四：跨模型幻觉一致性分析

### 5.1 原理

如果一个样本被多个模型同时答错（即被多个模型的 Judge 判定为含幻觉），则该样本可能存在固有的歧义性、标注质量问题或异常难度。反之，如果各模型答错的样本完全不重合，则幻觉主要表现为模型特异性的行为，而非数据问题。该分析类似于机器学习中的"难度分析"（Item Response Theory）和"标注质量分析"（Annotation Noise Analysis）。

### 5.2 方法

**幻觉重叠统计**：对每个数据集（MathVista Direct、VQA-RAD、POPE 三 split），统计每条样本被多少个模型判定为含幻觉（0-4 个）。输出幻觉重叠分布：

| 重叠数 | 含义 |
|--------|------|
| 0/4 | 所有模型均正确，无争议样本 |
| 1/4 | 仅一个模型答错，模型特异性幻觉 |
| 2/4 | 两个模型答错 |
| 3/4 | 三个模型答错 |
| 4/4 | 所有模型答错，"极端困难样本" |

**样本级聚类**：对重叠数 ≥ 3 的样本，人工归因分析其共同特征（问题类型、视觉复杂度、答案形式等），判断是否为数据集标注问题或固有问题。

**跨数据集对比**：对比不同数据集上的重叠分布。高重叠比例的数据集可能说明该数据集的样本难度差异较大，存在"简单-困难"两极分化。

### 5.3 参考文献

1. Rodriguez et al., "Item Response Theory for Natural Language Understanding", 2021.
2. Platanios et al., "Estimating Accuracy from Unlabeled Data", 2016.
