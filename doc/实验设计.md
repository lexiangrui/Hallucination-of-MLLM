## 三、实验一：POPE 物体幻觉检测

### 3.1 目的

评估各模型在物体存在性判断任务上的幻觉率，分析三种难度梯度（random < popular < adversarial）下的性能变化规律。

### 3.2 检测方法

规则判断法流水线：
```
模型回答 → 提取首句 → 去除标点 → 检测否定词 → 归一化为 Yes/No → 与 GT 对比
```

幻觉判定：模型回答 `yes` 且 GT 为 `no` → FP，记为**对象幻觉**。

### 3.4 CoT（思维链）对 POPE 幻觉的影响

POPE 为二元 Yes/No 判断任务，本实验中仅使用 Direct 模式（要求模型直接回答 Yes 或 No）。POPE 任务本身不涉及 CoT 实验设计，原因如下：

1. **任务形式限制**：POPE 的答案空间为二元分类（Yes/No），引入 CoT 不会改变最终判定的信息量，规则归一化仍只提取 Yes/No
2. **幻觉类型单一**：POPE 仅覆盖 Faithfulness（物体存在性）幻觉，不涉及推理链条中的 Logical 错误，因此 CoT 的核心收益（减少逻辑推理错误）在此任务上无法体现
3. **实验效率考量**：CoT 会显著增加回答长度和 API 调用成本，但对 Yes/No 二分类的判定结果影响有限

CoT 对幻觉的影响分析集中在实验二（MathVista），详见第四章 4.5 节。

## 四、实验二：MathVista 数学推理幻觉检测

### 4.1 目的

评估各模型在复杂图文推理任务上的幻觉率，分析幻觉类型分布（Faithfulness / Factuality / Logical），并通过 Direct 与 CoT 对比实验量化思维链对幻觉的影响。

### 4.2 检测方法

GPT Judge（MMHal-Bench 协议）：
- 输入：图像 + 问题 + 模型回答 + ground truth
- 输出：0–6 分 Likert 评分 + 幻觉类型标签（faithfulness / factuality / logical / none）
- 判定阈值：score < 3 → 存在幻觉；score ≥ 3 → 无幻觉

### 4.3 实验设置

- **数据集**：MathVista testmini（1000 条）
- **提示策略**：
  - Direct 模式：要求直接输出最终答案
  - CoT 模式：要求逐步推理，最终以 `Final answer:` 结尾
- **模型**：GPT-5.4-mini、Gemini 2.5 Flash、Qwen3.5-35B-A3B、Qwen3-VL-235B-A22B-Instruct（四模型均跑 Direct + CoT）

## 七、误差分析二：裁判模型 Temperature 对检测结果的影响

### 7.1 目的

量化 GPT Judge 中 temperature 参数对幻觉检测结果的影响，评估当前 temperature=0.0 设置的稳定性，为方法可靠性提供误差界估计。

### 7.2 实验设置

- **样本**：每个模型从 MathVista CoT 结果中取前 100 条样本（固定子集，保证跨 temperature 可比性）
- **模型**：GPT-5.4-mini、Gemini 2.5 Flash、Qwen3.5-35B-A3B、Qwen3-VL-235B-A22B-Instruct
- **Temperature 取值**：0.0（基准）、0.3、0.7、1.0
- **重复次数**：每个 temperature 独立运行 1 次（共 4×4=16 次 Judge 调用批次）
