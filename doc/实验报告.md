# 多模态大模型幻觉检测实验报告

---

## 摘要

多模态大模型（MLLM）在视觉问答和图文推理中展现出强大能力，但仍容易出现幻觉：输出与视觉输入不一致、与既定世界知识相矛盾、或推理过程中存在缺陷。本报告提出了一个系统化的框架，用于检测和评估 MLLM 中的幻觉。我采用一个三分类体系，涵盖忠实性（faithfulness）、事实性（factuality）和逻辑性（logical）幻觉，并在三个基准（POPE、MathVista、VQA-RAD）上使用两种互补的检测方法评估四个代表性模型（GPT-5.4-mini、Gemini 2.5 Flash、Qwen3.5-35B-A3B、Qwen3-VL-235B-A22B）：用于二元探测的规则判断流程，以及遵循 MMHal-Bench 0–6 Likert 量表的 MLLM-Judge 协议，以 GPT-5.5 作为主要 Judge。得出三个发现。(1) 模型排名在不同任务领域之间发生反转，视觉编码器容量和回答偏向校准的二维视角解释了 POPE 上的面板排序以及 MathVista 和 VQA-RAD 上的排名变化。(2) 思维链提示的效果取决于基线水平：它显著减少了弱基线模型的幻觉（GPT-5.4-mini −10.7 pp, Gemini 2.5 Flash −6.7 pp），但加剧了强基线模型的幻觉（Qwen3-VL +7.7 pp），通过两种具体识别的机制：暴露效应（推理链使潜伏的感知错误显式化）和承诺错误（围绕早期错误前提的雪球式扩展）。(3) 在医学 VQA 中，忠实性幻觉占所有幻觉的 96% 以上，一种反复出现的"自信但错误"的失败模式（模型准确背诵领域惯例但却错误地定位了解剖发现）表明，流畅的医学知识并不等同于医学视觉感知。五个独立的误差分析（人类对齐 Cohen's κ = 0.70，GPT-5.5 与 Claude Opus 4.7 之间的跨 Judge 一致性 κ = 0.78，阈值敏感性，长度偏差评估，以及跨模型重叠）确认了评估框架的稳健性，并将 Judge 与人类之间主要的残余分歧追溯到基础评分量表中信息量和幻觉两个维度的耦合。

## 1 引言

### 1.1 任务重述

多模态大模型在视觉问答和图文推理中展现出强大能力，但仍容易出现幻觉：输出与视觉输入不一致、与既定世界知识相矛盾、或存在有缺陷的推理。本报告研究 MLLM 中的幻觉检测与评估。考核要求总结如下：

1. **幻觉定义与分类**：明确定义至少 2 类幻觉类型，提供清晰解释，并为每类提供不少于 2 个示例。
2. **自动化检测方法与评估指标**：构建不少于 2 种检测方法（如规则方法、MLLM-Judge 协议），并设计不少于 2 种评估指标。
3. **实验评估（主任务）**：在通用视觉问答（如 POPE）和推荐的图文推理基准（MathVista 或 ChartQA）上评估至少 2 个模型，包括 1 个闭源和 1 个开源模型。
4. **人类对齐验证（Human-as-Judge）**：构建一个小规模人工标注集（20–50 条样本）作为金标准，比较自动检测结果与人工判断，并分析不一致案例。
5. **分析要求**：包含 CoT 对幻觉的影响分析、模型间对比分析，以及不少于 2 个典型 Failure Case 的深入分析。
6. **加分项**：将评估扩展到其他图文任务或特定领域（如 OCR、医学、遥感），或进行跨任务泛化分析。

## 2 多模态大模型幻觉的定义与分类

幻觉仍然是多模态大模型面临的核心挑战。尽管不同研究采用不同的术语和视角，但在基本概念上已形成广泛共识。本节回顾三篇代表性综述 [6, 8, 7]，随后提出本文采用的分类体系。

**Bai 等（2025）** 将 MLLM 的幻觉定义为生成的文本与对应视觉内容不一致，强调跨模态不一致性。他们还将该概念追溯至 LLM，区分了事实性幻觉（与真实世界事实的偏差）和忠实性幻觉（偏离输入上下文或自洽性不足）。他们以对象为中心的分类包含三个层次：类别（捏造或错误识别物体）、属性（类别正确但颜色、形状、数量等属性错误）和关系（物体及属性正确但空间或交互关系错误）。

**Chen 等（2026）** 提出更宽泛的统一定义，将幻觉视为生成内容与输入条件或既定世界知识之间的任何不一致。他们的分类扩展了忠实性-事实性二分法：忠实性幻觉按视觉粒度分层为对象级、属性级和场景级错误，形成从浅层感知到更深层场景理解的递进结构；事实性幻觉分为常识错误和领域特定错误。

**Liu 等（2024）** 将幻觉限定于视觉领域，定义为图像的事实性视觉内容与生成文本之间的不一致。他们采用双视角分类：认知视角区分判断型幻觉（是与否的判断与视觉事实矛盾）和描述型幻觉（不忠实的自由生成），语义视角区分物体、属性和关系幻觉。

综合上述框架，并结合本实验主要针对视觉问答与图文推理的实际情况，我采用如下定义和三分类体系：

> **MLLM 的幻觉是指模型的回答与输入视觉内容不一致、与可验证的现实世界知识相矛盾、或其推理过程中存在缺陷。**

表 1 将该定义与上述三篇综述进行对比定位。

**表 1：三篇代表性综述与本文所采用框架的 MLLM 幻觉分类对比。底部行（灰色高亮）标识本报告全文使用的分类体系。**

| 来源 | 范围 | 主轴 | 子类别 |
|------|------|------|--------|
| Bai 等（2025） | 跨模态不一致性 | 事实性 vs. 忠实性 | 类别/属性/关系 |
| Chen 等（2026） | 广义不一致性 | 忠实性 vs. 事实性 | 忠实性：对象/属性/场景；事实性：常识/领域 |
| Liu 等（2024） | 仅视觉领域 | 判断型 vs. 描述型 | 物体/属性/关系 |
| **本文** | 视觉+知识+推理 | 三个正交分类 | 忠实性/事实性/逻辑性 |

以下详述三个类别。

### 2.1 Faithfulness 幻觉（视觉不一致）

忠实性幻觉指模型的回答与输入图像的视觉内容不一致。根据视觉粒度的不同，进一步分为三个子层次。

**对象级**：模型声称图中存在实际不存在的物体、遗漏实际存在的物体、或错误识别物体类别。POPE 基准通过二元探测问题系统检测此类幻觉（图 1a）。

**属性级**：模型正确识别物体类别，但错误描述其颜色、形状、材质、姿态等属性（图 1b）。

**场景级**：空间关系、交互事件或其他场景级描述与图像不一致，即使所有单个物体均被正确识别（图 1c）。

![Fig 1a: 对象级忠实性幻觉示例。](../report/figures/faith_object.pdf)

![Fig 1b: 属性级忠实性幻觉示例。](../report/figures/faith_attr.pdf)

![Fig 1c: 场景级忠实性幻觉示例。](../report/figures/faith_scene.pdf)

**核心检测问题**：输出是否与图像一致？

### 2.2 Factuality 幻觉（事实不一致）

事实性幻觉指模型的回答与既定、可验证的现实世界知识相矛盾。

**常识级**：错误涉及日常生活常识，模型的视觉感知大致正确，但输出与众所周知的事实相矛盾（图 2a）。

**领域特定级**：错误涉及专业领域知识。此类幻觉在 VQA-RAD 数据集中尤为常见（图 2b）。

![Fig 2a: 常识级事实性幻觉示例。](../report/figures/fact_common.pdf)

![Fig 2b: 领域特定级事实性幻觉示例。](../report/figures/fact_attr.pdf)

**核心检测问题**：输出是否与世界知识一致？

### 2.3 Logical 幻觉（推理错误）

逻辑性幻觉指模型的回答在推理过程中存在缺陷，结论无法从视觉证据或模型自身已建立的前提中合乎逻辑地推出。

**演绎推理错误**：模型正确读取了视觉信息，但通过错误的推理得出了矛盾的结论。此类错误，特别是数值推理失败，是 MathVista 中逻辑性幻觉的主要来源（图 3a）。

**因果推理错误**：模型推断了与视觉证据相矛盾的因果关系（图 3b）。

![Fig 3a: 演绎推理幻觉示例。](../report/figures/logic_deductive.pdf)

![Fig 3b: 因果推理幻觉示例。](../report/figures/logic_causal.pdf)

**核心检测问题**：推理是否有效？

## 3 实验设计

### 3.1 数据集、检测方法与评估指标

#### 3.1.1 POPE：物体存在性幻觉检测

POPE 的检测方法采用规则匹配法。

**Prompt 与后处理。** 在回答生成阶段，模型接收的 prompt 仅包含问题本身和回答 Yes 或 No 的指令，以确保简洁且可解析的回答（完整 prompt 模板详见附录 A）。答案后处理算法遵循 RUCAIBox/POPE 官方仓库的评估脚本，伪代码如下：

```
Algorithm 1: POPE answer normalization
Require: Model response r, a free-form text string
Ensure: Normalized answer a ∈ {"yes", "no"}
  s ← first sentence of r                     // split by "."
  remove all commas from s
  W ← split s by whitespace into a set of words
  if "No" ∈ W or "not" ∈ W or "no" ∈ W then
      return "no"
  end if
  return "yes"
```

**POPE 中的物体幻觉。** 在该协议下，模型回答 yes 而真实标签为 no 时记为一次物体幻觉。在二元分类视角中这是一个假阳性，并实例化了分类中的对象级忠实性类别。

评估指标以 yes（物体存在）作为正类，因此物体幻觉对应假阳性。核心指标总结如下：

| 指标 | 公式 | 说明 |
|------|------|------|
| Accuracy | (TP+TN)/N | 整体正确率 |
| Precision | TP/(TP+FP) | 预测为 Yes 时的准确率 |
| Recall | TP/(TP+FN) | 实际为 Yes 时的检出率 |
| F1 | 2·P·R/(P+R) | Precision 与 Recall 的调和平均 |
| Yes Ratio | N_yes/N | 回答偏向性指标 |
| Hallucination Rate (HR) | FP/N | 核心指标；等于物体幻觉率 |

#### 3.1.2 MathVista：数学推理幻觉检测

**检测方法。** MathVista 的检测方法采用 MLLM Judge，遵循 MMHal-Bench 评估协议 [4]，采用 0–6 分 Likert 量表联合评估每条回答的信息量和幻觉程度。阈值 3 分区分两个区间：低于 3 分表示存在幻觉，3 分及以上表示无幻觉。GPT-5.5 在本实现中担任 Judge。Judge 的系统 prompt 定义了评分量表、幻觉判定标准和三分类类型，并配备 5 个 few-shot 示例以保证评估一致性。当 Judge 评分低于 3 分时，额外标注具体的幻觉类型（faithfulness、factuality 或 logical）。完整的 prompt 模板（回答生成和 Judge 评分）详见附录 A。

**Prompt 构建。** 在回答生成阶段，prompt 根据样本元数据动态构建以产生格式特定的指令。Direct 模式下，prompt 由问题文本和格式指令拼接而成。CoT 模式则在 Direct 基础上要求逐步推理，并以 "Final answer:" 标记最终答案。两种模式均进行了评测，以分析显式推理对幻觉行为的影响。

评估指标如下：

| 指标 | 定义 | 说明 |
|------|------|------|
| Hallucination Rate (HR) | N\_score<3 / N\_total | 越低越好 |
| Average Score | sum score_i / N | 整体回答质量 |
| 分类型计数 | 按 faithfulness/factuality/logical 统计 | 幻觉来源细分 |

#### 3.1.3 VQA-RAD：医学视觉问答幻觉检测

**医学适配。** VQA-RAD 的检测方法复用 MLLM Judge 协议（0–6 分 Likert 量表，阈值 3 分），并针对医学场景进行了 domain-specific prompt 适配（详见附录 A）。Judge 的任务描述被替换为放射科场景描述，要求 Judge 同时核对回答与图像视觉内容以及既定医学和解剖学知识的一致性。在回答生成阶段，采用放射科专家角色 prompt，遵循 Wu 等（2024）的角色设定策略 [22]。三类幻觉类型分类（faithfulness、factuality、logical）始终启用，且幻觉率额外按 closed-ended 和 open-ended 答案类型分层统计。

使用完整的 451 条 test split，包含 251 条 closed-ended（yes/no）和 200 条 open-ended（自由文本）问题。评估指标包括 Hallucination Rate、Average Score、分类型幻觉计数，以及按答案类型分层的幻觉率。

所有四个模型均通过 API 调用，统一使用随机种子 42。温度保持各平台默认设置，最大 Token 无限制。POPE 每 split 采样 1000 条，MathVista 使用完整 testmini 集（1000 条），VQA-RAD 使用 test split（451 条）。GPT-5.5 全程担任 MLLM Judge。

### 4.2 结果分析

#### 4.2.1 三个 Split 探测三种错误机制

**单调难度梯度。** 从 Random 到 Popular 到 Adversarial，所有模型的 Hallucination Rate 均严格单调递增（表 3），验证了 POPE 三层次负样本采样策略的有效性。然而，除了难度排序外，三个 split 还暴露了三种性质上不同的错误机制，清晰地映射到忠实性分类上。

**Random split：对象级感知。** 负样本均匀采样，因此大多数候选物体与场景在视觉上无关（例如在厨房照片中询问 car）。四个模型的 HR 均在 0.30%–1.10% 之间，表明拒绝明显不存在的物体的基线能力已接近饱和。因此，该 split 测量的是原始的对象级视觉感知，几乎没有语言先验的干扰。

**Popular split：对语言先验的抵抗。** 负样本是高频共现类别，在统计上与场景关联但在该特定图像中不存在（例如在户外饮食场景中询问 backpack）。HR 急剧上升至 2.40%–6.20%，约为 Random 水平的 5–8 倍。这一跃升分离出了语言先验偏差的贡献：当视觉证据模糊时，模型退回到预训练期间学习到的统计共现模式。

**Adversarial split：细粒度语义判别。** 负样本与图像中确实出现的物体语义相似（例如当只有 teddy bear 出现时询问 bear）。HR 进一步上升至 4.80%–8.90%，模型不再能依赖场景级关联；视觉编码器必须分辨细粒度的语义边界。这种错误模式的根本原因——概念层级的混淆——无法仅通过扩大规模来解决。

总之，三个 split 共同诊断了一个对象级忠实性幻觉在感知—先验流程中的起源位置，而不仅仅是它发生的频率。

#### 4.2.2 模型对比分析

**Qwen 家族内部，视觉编码器容量占主导。** Qwen3-VL-235B 在每个 split 上取得最低 HR（0.30%、2.40%、4.80%）和在 Popular 和 Adversarial 上最高的 F1。与共享相同训练家族但使用更小激活视觉编码器（3B vs. 22B 激活参数）的 Qwen3.5-35B-A3B 相比，HR 持续低 50–75%。在固定语言骨干家族的情况下，视觉编码器规模因此是该家族内的主导因素；这一结论是否跨家族成立无法在此确定，因为闭源密集模型不公开视觉编码器参数。

**GPT-5.4-mini：具有不对称成本的保守策略。** GPT-5.4-mini 在所有模型中 Yes Ratio 最低（Random 0.414）且 Precision 最高（Random 0.9831）。这一保守画像产生较低的 FP 计数，但 FN 计数最高（Random 92），因此其幻觉主要表现为遗漏而非捏造。在安全敏感应用中，这一不对称成本可能是可取的（不发明物体通常是更优的），但它限制了可达的 F1：一旦 Yes/No 决策不能再安全地默认为"No"，Adversarial 上的 HR 相比 Random 上升了十倍以上（0.70% → 7.80%）。

**Gemini 2.5 Flash：非典型的 Popular–Adversarial 反转。** Gemini 是唯一一个 HR 从 Popular（5.70%）到 Adversarial（5.10%）下降的模型，尽管差距很小（0.6 pp）。由于标准解释（Adversarial 比 Popular 更难）对其他三个模型成立，这一反转表明 Gemini 的视觉感知对细粒度语义干扰物相对稳健，但对场景级共现先验相对敏感。一个合理的机制是将其回答更紧密地基于可见特征而非场景上下文的感知流程，这也与其中等但稳定的 Popular 表现一致。

**Qwen3.5-35B：最大的 split 难度斜率。** Qwen3.5-35B-A3B 表现出最陡的 HR 跨 split 增长（1.10% → 6.20% → 8.90%，增长 7.8 pp），为面板中最大。仅 3B 激活视觉参数，视觉编码器不足以支持细粒度判别，一旦负样本在语义上接近。高 Recall（三个 split 中三个最高）反映了相反的倾向于回答"Yes"的压力，这在面板最高的 Yes Ratio（Adversarial 0.529）中也可见。

**综合。** 前一小节诊断了错误在感知—先验流程中的起源位置，跨模型视角则识别了谁易受每种机制影响。对比突出了两个轴：视觉编码器容量，解释了 Qwen 两个模型之间的差距和 Gemini 的大致位置；以及回答偏向校准，将 GPT-5.4-mini 的保守画像与 Qwen 模型更许可的画像区分开来。处于高容量与均衡校准交点附近的模型（Qwen3-VL）主导排行榜；中等容量与许可性校准（Qwen3.5）在对抗压力下牺牲 precision；中等容量与保守校准（GPT-5.4-mini）牺牲 recall。这一二维视角将在 MathVista 和 VQA-RAD 的不同任务压力下再次出现。

### 4.3 Failure Case 分析

#### 4.3.1 Case 1：语义粒度混淆（Adversarial）

该案例实例化了在 4.2.1 节中识别的细粒度语义判别机制。图像包含一只 teddy bear、一个人和一本书。问题询问图中是否有一只 bear，ground truth 为 No。四个模型全部回答 Yes，表明这是一个系统性的错误而非个别模型的缺陷。

**根因：语义粒度混淆（Semantic Granularity Confusion）**

图像中真实存在的物体是 teddy bear（COCO 标签集中的一个独立类别 [15]），而问题问的是 bear（一种真实动物）。四个模型都在语义层面将"teddy bear"与"bear"关联起来，看到玩具就触发正向判断。这本质上是概念层级混淆：模型将视觉上相似的物体混同为语义上相同的物体。这种错误无法通过增加模型规模或提升视觉编码器分辨率来解决，因为它涉及的是语义表征中概念边界的清晰度，而非底层视觉特征的可区分性。

#### 4.3.2 Case 2：语言先验偏置（Popular）

该案例例证了 Popular split 分离出的语言先验偏差机制。图像显示一个人在三明治和热狗的户外场景中饮食。问题询问图中是否有一个 backpack，ground truth 为 No。同样，四个模型全部回答 Yes。

**根因：语言先验偏置（Linguistic Prior Bias）**

在户外有人饮食的场景中，"backpack"是一个高频共现物体。语言模块中的统计先验（户外 + 人物 + 饮食 → 背包概率高）压倒了视觉模块的实际感知，导致模型做出肯定回答。这正是 Popular split 利用的机制：模型用训练数据中的语言先验填补视觉不确定性。两个 case 的对比进一步证实，Popular 和 Adversarial split 针对不同的错误机制，Popular 主要利用语言先验，而 Adversarial 主要测试语义判别。

### 5.4 CoT 效果分析

#### 5.4.1 基线依赖的 CoT 效应

CoT 对 MathVista 的影响沿单一轴清晰划分：Direct 模式基线。Direct HR 高的模型（GPT-5.4-mini 45.1%，Gemini 34.3%）在 CoT 下显著改善，而 Direct HR 低的模型（Qwen3.5 13.3%，Qwen3-VL 16.3%）退步。所有四个变化在配对 McNemar 检验下均统计显著，尽管 p 值相差几个数量级：GPT 和 Qwen3-VL 的效果达到 p<10⁻⁹，而 Qwen3.5 +2.2pp 的变化则弱得多（p=0.016，95% CI [+0.5, +3.9]）。

#### 5.4.2 CoT 受益者：弱基线模型

CoT 显著改善了弱基线模型。GPT-5.4-mini 是最大受益者：HR 下降 10.7 个百分点，平均分提升 1.04，均为所有模型中最大。改善主要来自 logical 幻觉大幅减少（248→143，−42.3%）。Direct 模式下该模型仅输出选项字母（中位 1 词），将错误答案直接暴露给 Judge 而无任何推理证据。CoT 迫使模型逐步组织数学推导，修正了大量可通过推理链纠正的错误。样本级分析表明，209 例 Direct 模式幻觉在 CoT 下被修正，仅 102 例出现反向退化，净改善 +107 例。

Gemini 2.5 Flash 的改善路径不同：受益主要来自 faithfulness 幻觉减少（278→212，−23.7%）。CoT 要求模型在推理时明确引用视觉证据，迫使更仔细地审视图表内容，减少视觉误读。值得注意的是，Gemini 的 Direct 模式回答已高度详细（中位 242 词），其 CoT 回答反而略短（中位 228 词），表明 CoT 并未迫使更长的输出，而是通过约束推理依据图像可见证据来提高准确性。

#### 5.4.3 CoT 风险：强基线模型

CoT 为强基线模型引入了额外风险。两个 Qwen 模型均呈现极化模式：6 分和 2 分箱均增长，而中间 4–5 分塌缩，表明 CoT 将回答推向要么完美正确、要么详细错误的极端。

Qwen3.5-35B-A3B 呈现出 HR 上升 2.2 个百分点而平均分也从 5.00 升至 5.34 的模式。分数极化解释了这两个变动：6 分样本从 488 增至 810（拉高均值），2 分样本从 125 增至 154（详细但错误的推理被严格惩罚，拉高 HR）。由于该模型在 Direct 模式下已具备较强数学推理能力（logical 仅 30 例），CoT 的边际收益很小，反而因迫使显式视觉描述而暴露了视觉感知的盲区，导致 faithfulness 幻觉从 98 增至 124（+26 例，+26.5%）。

Qwen3-VL-235B 表现出更明显的模式：HR 从 16.3% 跃升至 24.0%（+7.7pp），净退化 77 例。其中 116 例 Direct 模式正确的样本在 CoT 下产生幻觉，仅 39 例反向改善。极化效应同样显著：6 分样本从 452 暴增至 723，但 2 分样本从 142 增至 194，0 分案例出现（0→8），中间 4–5 分几乎消失（93→6 和 291→30）。Faithfulness 幻觉从 113 增至 154（+41 例，+36.3%），表明强制显式视觉描述系统性地暴露了感知弱点。

#### 5.4.4 底层机制：暴露与承诺

这一现象与近期研究的发现一致。Liu 等（2025）通过注意力分析发现，推理链越长，模型对视觉输入的注意力越弱（注意力漂移），模型逐渐从图像内容漂移到语言先验，导致"更多思考反而更少看见" [9]。Kancheti 等（2025）评估了 17 个模型后报告，CoT 一致性地损害了视觉空间推理，模型会"从文本先验中幻觉出视觉细节" [10]。两个 Qwen 模型的 faithfulness 幻觉大幅增加与这两项观察均一致。

CoT 通过两种互补机制引入幻觉。

**暴露效应（Exposure effect）：** Direct 模式下被隐藏的视觉感知错误在 CoT 推理链中被显式描述出来，被 MLLM Judge 捕获。即便最终答案正确，中间步骤的视觉误读也会导致评分下降。这一机制解释了为何强基线模型尽管最终答案准确率高，HR 仍然增加。

**承诺错误（Commitment error）：** CoT 迫使模型在推理早期做出明确的视觉或数学断言。一旦某个中间步骤出错，模型会围绕错误前提继续推理，产生"信息丰富但错误"的回答（score 2）。Zhong 等（2024）提出的 Multimodal Hallucination Snowballing 框架直接对应这一机制：一旦模型在推理早期产生幻觉，它会围绕错误前提自洽地展开推理，使错误沿推理链传播和放大 [11]。

这两种机制共同作用：暴露效应揭示潜伏的感知错误，承诺错误将其转化为级联的推理失败。它们共同解释了为何 CoT 可以同时改善弱模型（通过结构化推理捕获逻辑错误）和削弱强模型（通过强制显式表达原本保持隐性和无害的视觉误读）。

### 5.5 Failure Case 分析

本节选取两个典型 Failure Case，分别对应 CoT 的两种核心副作用机制。

#### 5.5.1 Case 1：CoT 承诺错误导致逻辑幻觉（GPT-5.4-mini，PID=30）

**样本信息**

| 字段 | 内容 |
|------|------|
| 题目类型 | 几何推理（圆，多选题） |
| 问题 | 两弦 AB、CD 相交于 E；∠D = 35°，∠AEC = 105°。求 ∠C。 |
| Ground Truth | 70°（选项 B） |

![MathVista Case 1 图像：圆中相交弦](../report/figures/mathvista_pid30.jpg)

**两种模式回答对比**

| 模式 | 回答 | Score | 幻觉类型 |
|------|------|-------|---------|
| Direct | B（70°） | 5 | none |
| CoT | 推理过程错误，得出 80°（选项 C） | 1 | logical |

Direct 模式下，模型直接输出正确答案 B（70°）而不展示任何推理，Judge 评分 5。CoT 模式下，模型尝试逐步推理，但在第一步就做出了错误的承诺——将 ∠E=105° 作为已知条件处理，应用三角形内角和公式得到 ∠C = 180° − 105° − 35° = 40°。发现 40° 不在选项中后，模型又捏造了一个补角论证得到 80° 并选择选项 C。这展示了 Zhong 等（2024）描述的"雪球式幻觉"模式：一旦错误前提被锁定，后续步骤在其上构建，每一步看似孤立合理，但整个推理链建立在错误的初始假设上 [11]。

正确的做法应使用圆周角定理：∠AEC 是 ∠DEB 的对顶角，∠C = ∠AEC − ∠D = 105° − 35° = 70°。在 Direct 模式下，模型直接检索到了这一结果，但 CoT 迫使它阐述中间步骤，在其中它选择了错误的分解策略。这表明，当模型缺乏维持有效推理链所需的精确几何知识时，CoT 可以将正确的直觉转化为错误的答案。

#### 5.5.2 Case 2：CoT 暴露视觉感知错误导致忠实性幻觉（Qwen3-VL-235B，PID=15）

**样本信息**

| 字段 | 内容 |
|------|------|
| 题目类型 | 生物食物网图表推理（多选题） |
| 问题 | 如果藻类被消除，哪种生物受影响最大？ |
| Ground Truth | Common water flea（选项 B） |

![MathVista Case 2 图像：食物网图表](../report/figures/mathvista_pid15.jpg)

**两种模式回答对比**

| 模式 | 回答 | Score | 幻觉类型 |
|------|------|-------|---------|
| Direct | B（正确） | 5 | none |
| CoT | B（正确，但推理含视觉错误） | 2 | faithfulness |

Direct 模式下，模型输出正确答案，得分 5（无幻觉）。CoT 模式下，模型提供了详细的食物网分析，但错误地声称"Algae 有箭头指向 Tilapia"——实际上 Tilapia 从 Common water flea 和 Water plant 获取能量，并非直接来自 Algae。这是典型的暴露效应：在 Direct 模式下，模型可能通过某种捷径（语言先验或部分视觉感知）得出了正确答案，但其视觉感知并不完全准确。CoT 迫使模型显式描述图中的箭头关系，将这一视觉误读暴露给 MLLM Judge，导致评分从 5 降至 2。

这一案例揭示了 CoT 评估中的一个重要现象：**答案正确不等于推理正确**。CoT 模式下 MLLM Judge 同时评估推理过程和最终答案，即便答案正确，推理中的视觉不一致也会导致评分下降。这解释了为何 Qwen3-VL-235B 在 CoT 下 faithfulness 幻觉从 113 增至 154——其中相当一部分是"答案正确但推理含视觉错误"的案例，在 Direct 模式下这些错误被隐藏，在 CoT 模式下被暴露。

## 6 拓展实验：VQA-RAD 医学 VQA 幻觉检测

医学视觉问答是多模态大模型在高风险领域的典型应用场景。相较于通用 VQA 和数学推理，医学 VQA 对模型的视觉感知和领域知识提出了更高要求——模型需正确识别 X-ray、CT、MRI 图像中的解剖结构与病变，理解临床问题的语义学含义，并基于视觉证据给出诊断相关回答。本节以 VQA-RAD 数据集 [3] 为测试平台，评估四个模型在医学放射科场景下的幻觉表现。

### 6.1 数据集与检测方法

**数据集**：VQA-RAD 是医学 VQA 领域的标准基准。本实验使用 test split（451 条样本），其中 closed 问题（yes/no）251 条（55.7%），open 问题（自由文本回答）200 条（44.3%），随机种子 seed=42 采样。

**检测方法**：采用与 MathVista 相同的 MLLM Judge 评分协议（0–6 分 Likert 量表，MMHal-Bench 协议 [4]），阈值 3 分。针对医学场景，Judge prompt 的 task_desc 加入放射科场景描述。幻觉类型分类（faithfulness / factuality / logical）始终启用。

**分层评估**：额外按 closed / open 两种答案类型分层统计幻觉率，以分析不同回答形式对幻觉的影响。

### 6.2 总体结果

| **Average Score** | **4.52** | 2.68 | 4.20 | 3.57 |
| n_hallucinated | **150** | 299 | 177 | 263 |

| — Factuality | 1 (0.7%) | 2 (0.7%) | 4 (2.3%) | 5 (1.9%) |
| — Logical | 4 (2.7%) | 1 (0.3%) | 2 (1.1%) | 1 (0.4%) |
| None（无幻觉） | 301 | 152 | 274 | 188 |

**按答案类型分层**

### 6.3 分析

VQA-RAD 的评测结果揭示了与 MathVista 和 POPE 截然不同的模型表现格局。

**GPT-5.4-mini：强烈的双峰表现。** GPT-5.4-mini 总体领先，在 closed 和 open 两类问题上均取得最低 HR（33.26%）和最高平均分（4.52）。然而其分数分布呈强烈的双峰形态：142 条获 2 分（信息丰富但视觉错误），193 条获 6 分（完美回答），中间态相对较少。该模型并非全面优秀，而是在"自信且正确"和"自信且错误"之间切换，与在 POPE 上观察到的保守回答策略一致。

**模型排名反转。** 在 POPE 上全面领先的 Qwen3-VL-235B（HR=58.31%）和 MathVista 领先的 Qwen3.5-35B-A3B（HR=39.25%）在医学领域均大幅退步。相反，在 MathVista 上落后、在 POPE 上排名较弱的 GPT-5.4-mini 表现最佳。这一反转说明医学 VQA 依赖于不同的能力轴：并非通用视觉感知（POPE 所探测）也非图表式推理（MathVista 所探测），而是放射科特定的视觉感知——在 X-ray、CT 和 MRI 输入上定位解剖结构和病理发现的能力。通用 MLLM 的训练数据中放射科影像的覆盖显然不均匀。

**Faithfulness 主导错误画像。** Faithfulness 幻觉占所有幻觉的 96% 以上，与三种类型均充分呈现的 MathVista 形成鲜明对比。几乎所有幻觉都源于视觉误读而非逻辑或事实错误。医学 VQA 的核心挑战在于精确识别解剖结构和病变：胸部 X 光片上主动脉是否增宽，或脑 MRI 的哪个半球包含病变。当模型误判图像的解剖内容时，所有基于错误前提的下游回答都会被 Judge 归类为 faithfulness 幻觉。

### 6.4 Failure Case 分析

#### 6.4.1 Case 1：保守拒答导致主动脉瘤漏诊（Closed 问题，ID=0）

**样本信息**

| 字段 | 内容 |
|------|------|
| 问题 | Is there evidence of an aortic aneurysm? |
| 预期答案 | **Yes**（存在主动脉瘤） |
| 答案类型 | Closed（yes/no） |

![VQA-RAD Case 1 图像：胸部 X 光片](../report/figures/vqarad_fc_0.jpg)

**四模型回答**

| 模型 | 回答摘要 | Score | 幻觉类型 |
|------|---------|------:|---------|
| GPT-5.4-mini | No convincing evidence; mild aortic widening | 2 | faithfulness |
| Gemini 2.5 Flash | Limited sensitivity on chest X-ray, cannot confirm | 2 | faithfulness |
| Qwen3.5-35B-A3B | Evidence suggests descending aortic aneurysm | 6 | none |
| Qwen3-VL-235B | No clear radiographic evidence | 2 | faithfulness |

**三个模型趋同于不足性断言。** 四个模型中的三个（GPT-5.4-mini, Gemini 2.5 Flash, Qwen3-VL-235B）返回某种"无令人信服证据"的变体，尽管三个模型都描述了相关发现（纵隔轻度主动脉增宽或突出），但止步于将其称为诊断。感知成功；推理悄然弃权。只有 Qwen3.5-35B-A3B 将相同的观察转化为正确的阳性诊断并获最高分（6），确认放射学信号实际上可以从图像中恢复。

**保守策略从 POPE 泛化而来。** 在 POPE 上，GPT-5.4-mini 表现出保守回答画像，以最低的 Yes Ratio（Random 0.414）和最高的 Precision（Random 0.9831）为代价牺牲 recall。这一画像扩展到放射科场景中的四个模型中的三个。一个可能的驱动因素是医学敏感 prompt 上的保守对齐：排练好的安全措辞"无明确放射学证据；需要临床对照"正是医学指令调优数据会强化的那种临床可防御的非回答。无论确切的训练原因如何，经验效应是面板范围内对封闭式筛查问题的不足性断言偏差。

**临床筛查中的不对称成本。** 这一画像的临床成本比其 POPE 对应物更为尖锐。在 POPE 上默认回答 No 产生良性的遗漏；在放射科筛查问题上，同一行为变成了漏诊，因为假阴性阻止患者进入下游诊断路径——而这正是筛查问题的目的。因此，保守回答策略不能干净地在通用 VQA 和临床筛查之间迁移：在后一场景中，不足性断言本身成为危险结果，而非安全的默认。

#### 6.4.2 Case 2：医学知识凌驾于视觉证据之上（Open 问题，ID=102）

**样本信息**

| 字段 | 内容 |
|------|------|
| 问题 | 病变位于大脑的哪一侧？ |
| 预期答案 | **left** |
| 答案类型 | Open（自由文本） |

![VQA-RAD Case 2 图像：轴位脑 MRI](../report/figures/vqarad_fc_102.jpg)

**四模型回答**

| 模型 | 回答摘要 | Score | 幻觉类型 |
|------|---------|------:|---------|
| GPT-5.4-mini | 将病变定位在图像右侧（视觉正确），但错误应用惯例 → 得出患者右侧 | 2 | faithfulness |
| Gemini 2.5 Flash | 将脑 MRI 误读为腹部 CT；描述胆囊中的胆结石 | 0 | faithfulness |
| Qwen3.5-35B-A3B | 正确复述惯例，但**错误定位**高信号在图像左侧 → 得出患者右侧 | 2 | faithfulness |
| Qwen3-VL-235B | 以额外细节复述惯例（DWI，缺血），但将病变错误定位在"右侧额叶/顶叶"→ 患者右侧 | 2 | faithfulness |

**所有四个模型沿三条不同路径失败。** Gemini 完全误识别了成像模态，在明确无误的轴位脑 MRI 上描述腹部 CT 伴胆结石，代表了双峰分布中的 score-0 极端。其他三个模型通过两条相反的错误路径趋同于相同的错误答案（"患者右侧"）。GPT-5.4-mini 正确地在图像右侧看到病变，但颠倒了放射科惯例，将"图像右侧"等同于"患者右侧大脑"，尽管在行文中承认了该惯例。两个 Qwen 模型则相反：它们正确复述了惯例（Qwen3-VL 甚至在推理前说"患者的右侧出现在图像的左侧"），但随后错误定位了高信号本身，将其放在图像左侧（Qwen3.5）或直接放在患者右侧半球（Qwen3-VL）。一个自信的、临床措辞的"右侧"因此掩盖了两种不同的底层缺陷：GPT 中惯例应用错误，Qwen 对中视觉定位错误。

**语言先验凌驾于视觉证据。** 这一模式在更高抽象层次上呼应了 POPE Case 2。在 POPE 中，共现先验（户外 + 人物 + 饮食 → backpack）凌驾于视觉证据之上。在这里，三个非 Gemini 模型都默认为最排练好的临床措辞（"病变在大脑右侧"），每个通过不同的局部故障，但产生了相同的流畅、自信临床的错误答案。Qwen3-VL 甚至发布"**Final Answer: The lesion is on the RIGHT side of the brain**。"机制在结构上相同：当视觉证据在感知上具有挑战性时，强语言先验占上风。医学领域只是提高了赌注，因为这里的先验是赋予错误答案表面合理性的专家措辞。

#### 6.4.3 综合：有知识无感知

这两个案例共同勾勒出通用 MLLM 在放射科中的两种主导失败模式：Case 1 中的不足性断言（面板描述发现但拒绝将其转化为诊断，在筛查问题上产生假阴性），和 Case 2 中的过度断言（面板生成排练好的临床措辞，即使视觉或惯例步骤出错，在错误半球上产生假阳性）。两条路径均被 Judge 归类为 faithfulness 幻觉，这解释了该类别在四个模型中 >96% 的近乎垄断地位。

两种模式都反映了一个单一的更深层差距。所有四个模型都能流畅地书写 DWI 序列、脑室周围白质和放射科医师视角惯例——语言骨干网络显然已经吸收的语言内容。它们不能可靠地做的是判断脑 MRI 的哪一半包含高信号病变，这是一个完全不涉及医学知识的感知任务。当视觉信号清晰时（Case 1），保守对齐抑制了正确答案；当视觉信号微弱时（Case 2），语言先验在其位置捏造了一个。简言之，流畅的医学知识并不等同于医学视觉能力。

## 7 误差分析

### 7.1 人类对齐验证（Human-as-Judge）

#### 7.1.1 实验设置

本实验旨在检验 GPT-5.5 Judge 的幻觉判定与人类标注者判断之间的一致性，借鉴 Omni-I2C [14] 的人类对齐方法论框架。评估指标包括 Accuracy、F1、Cohen's Kappa（衡量去随机化一致率）以及幻觉类型一致性（Type Agreement，衡量人机在幻觉类型判断上的一致比例）。Kappa 值按标准量表解释：<0.20 为轻微一致，0.21–0.40 为一般，0.41–0.60 为中等，0.61–0.80 为较高（Substantial），0.81–1.00 为几乎完全一致。

**采样策略**：从 MathVista testmini CoT 结果中层抽样 40 条样本（4 个模型各 10 条，每个模型内约 5 条幻觉、5 条无幻觉，固定随机种子 seed=42），在幻觉组内优先覆盖忠实性/事实性/逻辑性三类幻觉。标注界面逐条展示图像、题目、模型回答和参考答案。标注人员判断模型回答是否存在幻觉，若存在则标注幻觉类型（faithfulness / factuality / logical）。采用单盲设计（隐藏模型名称与 Judge 判定），避免标注偏差。

#### 7.1.2 整体结果

| 指标 | 数值 [95% CI] |
|------|--------------|
| Accuracy | 85.0% [70.9, 92.9] |
| Precision | 70.0% [48.1, 85.5] |
| Recall | 100.0% [78.5, 100.0] |
| F1 | 0.824 |
| Cohen's Kappa | 0.700 [0.481, 0.898] |

**混淆矩阵**：

| | MLLM Judge 有幻觉 | MLLM Judge 无幻觉 |
|--|-----------------:|-----------------:|
| 人标注有幻觉 | TP=14 | FN=0 |
| 人标注无幻觉 | FP=6 | TN=20 |

在人机均判定存在幻觉的 14 个样本中，Type Agreement 达到 92.9%（13/14）。

| Human \ GPT | faithfulness | factuality | logical |
|-------------|-------------:|----------:|--------:|
| faithfulness | 7 | 0 | 0 |
| factuality | 0 | 4 | 0 |
| logical | 1 | 0 | 2 |

**整体对齐良好，无遗漏幻觉。** 整体对齐为较高水平（κ = 0.70，95% CI [0.48, 0.90]）。对自动流程有效性至关重要的是，MLLM Judge 未遗漏任何人类识别的幻觉（Recall = 100%，95% CI [78.5, 100.0]）。错误画像是不对称的：Precision = 70%（95% CI [48.1, 85.5]）表明有 6 例过判（人类说无幻觉，Judge 说有幻觉），但零例漏判。对于自动化幻觉检测器，这是更可取的失败模式，因为下游使用可以重新检查被标记的案例，但无法从无声遗漏中恢复。

**根本原因：评分量表中的维度耦合。** 所有 6 例过判共享单一错误模式：年龄估算问题，模型产生合理的拒答（如"无法从外貌判断年龄"），被 MLLM Judge 误分类为 logical 幻觉。根本原因在于 MMHal-Bench 评分量表中"信息量"和"幻觉"维度的耦合：score=3 是唯一匹配"信息量低 + 无幻觉"的档位，但由于模型的拒答包含一定信息量（解释拒答原因），Judge 倾向于评分为 1–2，将样本推入"含幻觉"类别。因此，评分量表缺少一个用于"中等信息量且无幻觉"回答的中间档位，这指向一个具体的改进目标（增加一个中等信息量无幻觉的档位），以备 MMHal-Bench 量表在未来修订时使用。一个注意事项：由于 40 样本分层池偏向幻觉案例而非良性拒答，这一单一模式的普遍性应在更大且分层较少的样本上重新检验后才能推广。

### 7.2 Judge 模型一致性检验

**目的**：检验 GPT-5.5 Judge 与 Claude Opus 4.7 Judge 在同一批样本上的评估一致性，判断评估结论是否依赖于 Judge 模型的选择。

**方法**：从 MathVista testmini 中随机抽取 100 条样本（seed=42），4 个模型各 100 条回答。两个 Judge 使用完全相同的 system prompt（MMHal-Bench 0-6 评分协议 + 5 个 few-shot 示例 + 幻觉类型分类）。

| 模型 | N | GPT HR | Claude HR | ΔHR | GPT Avg | Claude Avg | Kappa | Spearman ρ |
|------|--:|-------:|----------:|----:|--------:|----------:|------:|----------:|
| GPT-5.4-mini | 100 | 45.0% | 44.0% | −1.0pp | 3.27 | 3.01 | 0.980 | 0.805 |
| Gemini 2.5 Flash | 100 | 37.0% | 27.0% | −10.0pp | 4.30 | 4.40 | 0.591 | 0.658 |
| Qwen3.5-35B-A3B | 100 | 14.0% | 18.0% | +4.0pp | 5.01 | 4.61 | 0.777 | 0.722 |
| Qwen3-VL-235B | 100 | 15.0% | 22.0% | +7.0pp | 4.91 | 4.38 | 0.638 | 0.669 |
| **Overall** | 400 | — | — | — | — | — | **0.776** | **0.740** |

*注：Overall Kappa 和 ρ 是跨 400 个样本合并计算，并非逐模型值的算术平均。Overall Pearson r = 0.762（p < 0.001）。*

**较高一致性且排名保持。** 两个 Judge 整体呈现较高的一致性（κ = 0.776，Spearman ρ = 0.740），并且模型相对排名在两个 Judge 下均一致：Qwen 系列最好，GPT-5.4-mini 居中，Gemini 2.5 Flash 最弱。最大的逐模型分歧出现在 Gemini（κ = 0.591）：Claude 对 Gemini 的 HR 评分比 GPT-5.5 低 10pp，表明 Gemini 的冗长回答更接近两个 Judge 对"信息丰富但错误"校准的分歧边界。GPT-5.4-mini 则相反最为稳定（κ = 0.98），很可能因为其通常单 token 的 Direct 回答几乎没有留给 Judge 解释的空间。这些结论基于两个前沿闭源 Judge，应在开源或领域特定 Judge 可用时重新检验。

| Qwen3-VL-235B | 2.1% | 16.3% | 16.4% | −14.2pp | +0.1pp |

![Fig 4: Hallucination rate as a function of threshold T (MathVista Direct). Vertical dashed line marks the official threshold T=3.](../report/figures/fig3_threshold_sensitivity_line.pdf)

**双峰分数分布；排名对阈值稳健。** HR(T=3) 和 HR(T=4) 几乎完全相同（差异 <0.3pp），这意味着极少样本得到 score=3，Judge 的分数呈清晰的双峰分布。最大跳跃发生在 T=2 到 T=3 之间（12.5–33.1pp），表明样本集中在 score=2。模型排名在三个阈值下完全一致，因此核心结论对阈值选择不敏感。

### 7.4 评分者长度偏差分析

**目的**：检验 MLLM Judge 是否存在系统性长度偏差。

**方法**：对 MathVista Direct 和 CoT 的全部样本，计算回答长度（词数）与 Judge score 的 Spearman 相关系数。

| 模型 | Direct ρ | CoT ρ | Direct 中位词数 | CoT 中位词数 | Direct Q1→Q4 Avg | CoT Q1→Q4 Avg |
|------|---------:|------:|-------------:|------------:|----------------:|--------------:|
| GPT-5.4-mini | +0.086** | +0.015 | 1 | 43 | 3.19→3.46 | 4.17→3.95 |
| Gemini 2.5 Flash | −0.142*** | −0.218*** | 242 | 228 | 4.61→3.80 | 5.30→4.33 |
| Qwen3.5-35B-A3B | +0.530*** | +0.006 | 42 | 122 | 4.56→5.33 | 5.32→5.26 |
| Qwen3-VL-235B | +0.394*** | −0.241*** | 40 | 103 | 4.38→4.92 | 5.32→4.32 |

（**p<0.01, ***p<0.001）

**不存在统一的长度偏差；CoT 改变符号方向。** Judge 未表现出统一的"越长→分数越高"偏差：相关性的符号取决于每个模型回答的质量模式。当较长回答携带更多有效推理时呈正相关（两个 Qwen 模型在 Direct 模式下），当较长回答引入更多错误时呈负相关（Gemini，以及 Qwen3-VL 在 CoT 下）。Qwen3.5 Direct 相关性 +0.530 为面板中最强，但相应的 Q1→Q4 进展（4.56 → 5.33）表明较长四分位的回答在绝对分数上确实更好，表明"因为更正确所以更长"而非"因为更长所以分数更高"。

切换到 CoT 通常消除或反转正相关：Qwen3.5 从 +0.530 降至接近零，Qwen3-VL 从 +0.394 翻转为 −0.241。这一模式与 MathVista 中识别的暴露效应一致：在 CoT 下，较长的推理链包含更多视觉断言，因此有更多机会被惩罚，所以 Judge 对较长推理链中的噪声更敏感。

### 7.5 跨模型幻觉一致性分析

**目的**：分析各数据集上不同模型的幻觉重叠模式——对每条样本统计被多少模型判定为含幻觉（0–4 个）。

| 数据集 | N | 0/4 | 1/4 | 2/4 | 3/4 | 4/4 | Hard Ratio(≥3/4) |
|--------|--:|----:|----:|----:|----:|----:|----------------:|
| MathVista Direct | 1000 | 387 | 321 | 175 | 49 | 68 | **11.7%** |
| MathVista CoT | 1000 | 487 | 232 | 132 | 77 | 72 | **14.9%** |
| VQA-RAD | 451 | 59 | 118 | 122 | 81 | 71 | **33.7%** |

![Fig 5: Radar chart comparing model performance across six dimensions (accuracy = 1 − HR). Larger area indicates better overall capability.](../report/figures/fig5_radar_comparison.pdf)

**VQA-RAD 的难度本质上是内在的。** 在 VQA-RAD 上，仅 13.1% 的样本（59/451）被所有四个模型正确回答，33.7% 被三个或更多模型答错。这种在频谱"困难"端的集中表明存在大量难度内在的数据项，而非特定于任何单个模型。这一发现强化了 VQA-RAD 章节的解读：高幻觉率并非由一个或两个模型的特性弱点驱动，而是由通用 MLLM 共有的领域级感知差距驱动，与 Case 2 的"知识 ≠ 感知"诊断一致。

**MathVista 与 CoT 的极化特征。** MathVista Direct 分布更均匀（38.7% 全正确，6.8% 全错误）。CoT 下 Hard Ratio 从 11.7% 升至 14.9%，这是一个适度但一致的转变，与 MathVista 章节已记录的 CoT 极化效应一致：CoT 将回答推向要么全对要么全错的极端，因此两个尾端的分布增长而中间单元格收缩。

## 8 局限性与未来工作

### 8.1 当前评估的局限性

**基准覆盖范围窄。** 三个数据集（POPE, MathVista, VQA-RAD）探测了三种不同的幻觉机制（物体存在性、数学推理和医学视觉定位），但并未涵盖公开可用幻觉基准的完整图景。HallusionBench [23]（视觉错觉和语言上下文操作）、AMBER [24]（一个多维度的无 LLM 基准，覆盖存在性、属性和关系幻觉），以及更广泛的能力套件如 MM-Vet [25] 和 MMBench [26] 未被纳入。本文识别的模式（特别是 MathVista 上的 CoT 极化效应和 VQA-RAD 上的知识—感知差距）是否能泛化到这些探测尚未被测试。

**模型面板受限。** 来自三个家族（OpenAI、Google、Alibaba）的四个模型被评估。较小的开源权重模型（如 LLaVA、MiniGPT 和 InstructBLIP 家族）以及单一家族内的参数规模消融实验被排除，因此本报告无法将模型规模驱动的效应与训练方法论或视觉编码器选择驱动的效应区分开来。

**人类对齐样本有限。** 40 样本标注池产生了整体 Cohen's κ = 0.70，95% bootstrap CI [0.48, 0.90]，其宽度足以在总体上将一致性表征为较高水平，但不足以支持统计上有依据的逐模型 Judge 可靠性排名。需要扩大规模的标注工作（约 N ≥ 80 每模型）才能做出此类定量跨模型论断。

### 8.2 未来改进方向

**语言先验对视觉内容的凌驾。** 最近，在与 GPT-5.5 的一次随意对话中，我注意到了一个有趣的现象：当我在一对艾宾浩斯风格的图像上问"哪个橙色球更大？"时，模型在两个输入上给出了相同的答案，尽管第二张图像根本不是真实的错觉。我觉得引人注目的是，这本质上与 POPE Popular split 中识别的机制相同——一旦存在熟悉的上下文线索，模型就会退回到共现统计量；艾宾浩斯探测只是将其推到了极端，其中记忆化的关联"艾宾浩斯图像 ⇒ 大小相等"似乎完全凌驾于图像信号之上。这与 Liu 等（2025）报告的推理时视觉脱离以及 Bai 等（2025）调查的更广泛的语言先验失败模式一致 [9, 6]。

**一种受 LAST-ViT 启发的补救思路。** 我恰好读到一篇最近的文章，它解决了纯视觉侧的结构性类似问题。Shi 等（2026）观察到，在标准 Vision Transformer 中，模型的汇总表示（CLS token，它收集来自所有图像块的信息然后用于做出最终预测）倾向于从图像的背景区域而非照片的实际主体中提取其大部分内容。原因相当平凡：背景块在面积上简单超过前景块，且标准训练目标仅检查最终的图像级标签是否正确，而不约束模型实际关注哪些块。他们提出的修复方案（名为 LAST-ViT）是一个轻量级即插即用模块，重新加权块信息如何聚合成 CLS token，将其偏向回前景，无需对骨干网络进行任何重新训练。该论文报告了在十二个视觉基准上的一致增益。修复的定性效果是：普通 Transformer 将注意力分散在背景块上，而 LAST-ViT 变体则将注意力集中在照片的实际主体上。

阅读那篇文章与我自己的艾宾浩斯观察并列，我开始思考同类型的捷径是否也在 MLLM 中起作用，只是沿不同的轴：不是单张图像中背景块淹没前景块，而是语言先验跨整个对话轮次淹没图像信号。一个具体的下一步是构建上述探测的配对的错觉和反错觉测试集，然后研究在解码时是否可以通过类似的重新加权——每当语言先验和图像内容不一致时将模型的注意力拉回视觉 token——来减少这一失败模式，同时不损害语言先验真正有用的任务上的表现。这目前仍是一个猜想，有待在注意力模式可直接检查和编辑的开源权重 MLLM 上进行受控实验。

## 附录 A：数据集详情与 Prompt 模板

### A.1 数据集详情

**POPE**：POPE（Polling-based Object Probing Evaluation）是一个基于 COCO 数据集构建的评测基准，旨在将物体幻觉的评估转化为二分类的对象存在性探测任务 [1]。该评估范式最早由 Rohrbach 等（2018）在图像描述对象幻觉研究中提出，后经 Li 等（2023）系统化为稳定探测协议 [13]。给定一张 COCO 图像及其标注物体，POPE 每张图像采样六个探测问题：三个正向（询问 ground-truth 存在的物体）和三个负向（询问 ground-truth 不存在的物体）。每个问题遵循固定模板"Is there a/an \<object\> in the image?"，期望 Yes/No 回答。三个 split 唯一的区别在于负样本的采样方式：

- **Random**：负样本从 COCO 标签集中均匀采样，排除图像中存在的物体。
- **Popular**：负样本从 top-K 最常见 COCO 类别中采样，同样排除存在的物体，创建高频共现干扰物。
- **Adversarial**：对每张图像，选取在 COCO 训练统计中与现存物体最频繁共现的三个类别作为负样本，产生语义相似的干扰物。

三个 split 诱导单调难度梯度，在 4.2.1 节中得到实证确认。每个 split 包含 3000 个探测问题（500 张图像 × 6 问题），ground-truth 分布平衡（1500 Yes / 1500 No）。官方评估报告 Accuracy、Precision、Recall、F1 和 Yes Ratio。本实验中，每个 split 子采样 1000 条（seed=42），每模型共 3000 条评估样本。

**MathVista**：MathVista 是一个专为评估基础模型在视觉语境下数学推理能力而设计的综合性评测基准 [2]。该基准整合了 31 个源数据集：28 个现有的多模态数学或 VQA 数据集和 3 个作者新建的数据集（IQTest、FunctionQA、PaperQA）。每个样本用两个正交分类法标注：五个任务类型（图形问答 FQA、几何问题求解 GPS、数学文字题 MWP、教材问答 TQA、视觉问答 VQA）和七种数学推理技能（代数、算术、几何、逻辑、数值常识、科学、统计推理）。问题以两种回答格式出现：多项选择和自由形式（整数、浮点数或短文本）。基准共包含 6,141 个样本，划分为 1,000 样本的 testmini 子集（带公开答案，用于模型开发）和 5,141 样本的 test 子集（带私有答案，用于排行榜）。本实验使用完整的 testmini 子集（1,000 样本），在 Direct 和 CoT 两种 prompt 模式下进行，每模型共 2,000 条评估样本。

**VQA-RAD**：VQA-RAD 是医学视觉问答领域的标准测试基准 [3]，是第一个由临床医生直接从放射科图像（来自 MedPix 开放教学库）生成问题和参考答案的医学 VQA 数据集。数据集包含 3,515 个问答对，覆盖 315 张图像，图像集合在模态上经过刻意平衡（约 104 张头部轴位 CT/MRI、107 张胸部 X 光片和 104 张腹部轴位 CT 切片）。每个问题标注为 11 个类别之一：模态、层面、器官系统、异常、物体/条件存在性、位置推理、颜色、大小、属性（其他）、计数和其他。答案分为自由形式（43.1%，1,515 对）和封闭式（56.9%，2,000 对）；在封闭式部分中，约 92% 是 Yes/No 问题。官方 test split 由 451 个 QA 对组成。本实验使用完整的官方 451 项 test split。

### A.5 MLLM Judge Prompt

**System prompt**：定义了 MMHal-Bench 0-6 分评分量表、幻觉判定标准和三种幻觉类型（faithfulness、factuality、logical），并配备 5 个 few-shot 示例和一个重要提醒。

评分量表定义：
- **6**: 信息丰富，有良好分析/推理，无幻觉
- **5**: 信息丰富，无幻觉
- **4**: 有一定信息量，无幻觉
- **3**: 无信息量（如"I don't know"），但无幻觉
- **2**: 信息丰富，有幻觉
- **1**: 有一定信息量，有幻觉
- **0**: 无信息量，有幻觉

幻觉类型定义（仅在 score < 3 时使用）：
- **faithfulness**: 视觉不一致——描述图像中不存在的物体/属性/关系
- **factuality**: 与既定世界知识相矛盾
- **logical**: 推理错误——结论不源于证据或自相矛盾

完整 system prompt 与实现中的 evaluation/judge.py 匹配。

**User prompt**：由数据集特定的 task_desc、问题、模型回答和参考答案构建。task_desc 按数据集选择：

```
# POPE
The question is a Yes/No object existence query.

# MathVista
The question requires mathematical visual reasoning (chart, diagram, or geometry).

# VQA-RAD
The question is about medical visual question answering based on a radiology image (X-ray, CT, or MRI). Carefully check whether the model's response is consistent with the visual content of the image and with established medical and anatomical knowledge.
```

用户 prompt 模板为：

```
{task_desc}

Question: {question}
Model Response: {model_response}
Ground Truth Answer: {ground_truth}

Please rate the model's response on the 0-6 scale.
```

以 MathVista pid=5 为例，GPT-5.4-mini 产生了正确的 CoT 回答（score 6）：

```
The question requires mathematical visual reasoning (chart, diagram, or geometry).

Question: Find m∠H
Choices: 97, 102, 107, 122
Model Response: The figure shows a pentagon with interior angles labeled: angle E = x, angle F = (x+20), angle G = (x+5), angle H = (x-5), angle J = (x+10). For a pentagon, the sum of interior angles is 540. So x + (x+20) + (x+5) + (x-5) + (x+10) = 540, 5x + 30 = 540, x = 102. Then m angle H = x - 5 = 97.
Final answer: A
Ground Truth Answer: 97

Please rate the model's response on the 0-6 scale.
```

Judge 返回形如 `{"score": 6, "has_hallucination": false, "hallucination_type": "none", "reason": "..."}` 的 JSON。
