# 多模态大模型幻觉检测结果与分析

---

## 一、实验概述

### 1.1 评测模型

| 模型 | 类型 | 说明 |
|------|------|------|
| GPT-5.4-mini | 闭源模型 | OpenAI 提供，通过 right.codes 调用 |
| Gemini-2.5-Flash | 闭源模型 | Google 提供，通过 YunWu AI 调用 |
| Qwen3.5-35B-A3B | 开源模型（MoE） | 阿里巴巴通义千问视觉模型，通过 SiliconFlow 调用 |
| Qwen3-VL-235B-A22B-Instruct | 开源模型（MoE） | 阿里巴巴通义千问视觉大模型，通过 SophNet 调用 |

### 1.2 评测数据集

| 数据集 | 任务类型 | 样本数 | 检测方法 |
|--------|----------|--------|----------|
| POPE (random split) | 二分类物体存在性判断（Yes/No） | 1000 | 规则判断法（rule-based） |
| POPE (popular split) | 同上，负样本为高频共现物体 | 1000 | 规则判断法（rule-based） |
| POPE (adversarial split) | 同上，负样本为易混淆物体 | 1000 | 规则判断法（rule-based） |
| MathVista (testmini) | 数学图文推理（多选/自由形式） | 1000 | GPT Judge（MMHal-Bench 协议） |
| VQA-RAD | 医学放射科图文问答（closed 56%/open 44%） | 451（从 test 集随机采样，seed=42） | GPT Judge（MMHal-Bench 协议） |

### 1.3 幻觉分类体系

本文定义三类幻觉：

| 类型 | 定义 | 典型表现 |
|------|------|----------|
| **Faithfulness（视觉不一致）** | 模型输出与图像视觉内容不一致 | 误判物体存在/不存在、颜色/形状/数量描述错误、空间关系错误 |
| **Factuality（事实不一致）** | 模型输出与可验证的世界知识矛盾 | 错误识别地标/名人、常识错误、学科领域事实错误 |
| **Logical（推理错误）** | 推理过程错误，结论无法从前提逻辑推导 | 计算错误、因果推断错误、模式推理错误 |

## 二、检测方法与评估指标

### 2.1 POPE 规则判断法

- **流程**：提取模型回答的首句 → 归一化 Yes/No → 与 ground truth 对比
- **幻觉定义**：predict="yes" 且 ground truth="no" → 物体幻觉（False Positive）
- **覆盖类型**：Faithfulness（物体存在性）

### 2.2 MathVista & VQA-RAD GPT Judge

- **流程**：将图像、问题、模型回答、ground truth 送入 GPT-5.5，遵循 MMHal-Bench 协议进行 0-6 分 Likert 评分
- **幻觉判定**：score < 3 → 存在幻觉；score ≥ 3 → 无幻觉
- **覆盖类型**：Faithfulness / Factuality / Logical（三类全覆盖）
- **VQA-RAD 特化**：Judge prompt 加入医学放射科场景描述；额外按 closed（yes/no）和 open（自由文本）两种答案类型分层统计幻觉率

### 2.3 评估指标

| 指标 | 公式/说明 | 适用任务 |
|------|-----------|----------|
| Accuracy | (TP + TN) / Total | POPE |
| Precision | TP / (TP + FP) | POPE |
| Recall | TP / (TP + FN) | POPE |
| F1 Score | 2 × P × R / (P + R) | POPE |
| Yes Ratio | N_pred="yes" / N_total | POPE |
| Object Hallucination Rate (OHR) | FP / Total | POPE |
| Hallucination Rate (HR) | N_score<3 / N_total | MathVista, VQA-RAD |
| Average Score | Σscore / N_valid | MathVista, VQA-RAD |
| Closed-ended HR | N_score<3 / N_closed | VQA-RAD（closed 问题） |
| Open-ended HR | N_score<3 / N_open | VQA-RAD（open 问题） |

#### 3.1.4 POPE 综合分析

- **Qwen3-VL-235B-A22B-Instruct 综合表现最优**：在三个 split 上 F1 均最高（0.9134/0.8908/0.8710），OHR 最低（0.30%/2.40%/4.80%），尤其在 Popular 和 Adversarial split 上优势明显，说明大参数 MoE 模型在细粒度物体识别上具有显著优势
- **Qwen3.5-35B-A3B 召回率最高**：在三个 split 上 Recall 均领先（0.8737/0.8697/0.8818），FN 最少，说明其对"物体存在"的判断更敏感，但代价是 FP 也最多（OHR 最高），在 Adversarial split 中 OHR 达到 8.90%
- **Gemini-2.5-Flash 表现均衡**：各项指标居中，在 Adversarial split 中表现突出（F1=0.8695，OHR=5.10%），与 Qwen3-VL 接近，说明其对易混淆负样本的鲁棒性较好
- **GPT-5.4-mini 在 Adversarial split 中表现最弱**：F1=0.8248，OHR=7.80%，在四个模型中垫底，说明其对语义相近物体的区分能力相对不足
- 所有模型均呈现清晰的难度梯度：Random < Popular < Adversarial，准确率从 ~90% 降至 ~85%，OHR 从 <1% 升至 5%–9%
- 所有模型均偏向保守（Yes Ratio 约 0.41–0.53），FN 多于 FP，即漏检（物体存在但回答 No）比误判（物体不存在但回答 Yes）更常见
- Qwen3.5-35B-A3B 的 Yes Ratio 最高（0.45–0.53），说明其回答 Yes 的倾向最强，这解释了其 Recall 最高但 Precision 最低的矛盾

- **GPT-5.4-mini 综合表现最优**：HR 最低（33.26%），平均分最高（4.52），在 closed 和 open 两类上均领先。其 6 分数量最多（193），说明在近半数样本上回答完全正确、信息详实且无幻觉
- **Qwen3.5-35B-A3B 居中**：HR=39.25%，平均分 4.20，在 open 问题上的幻觉率（48.50%）明显高于 closed（31.87%），说明开放回答场景对其更具挑战
- **Qwen3-VL-235B 表现偏弱**：HR=58.31%，平均分仅 3.57，虽然参数量最大（235B），但在医学 VQA 场景中未体现优势。Open 问题 HR 达 68.50%，超过半数开放回答存在幻觉
- **Gemini-2.5-Flash 表现最弱**：HR=66.30%，平均分 2.68，是所有模型中唯一平均分低于 3 的模型。0-2 分段占比 66.3%，说明大部分回答存在严重幻觉
- **Faithfulness 幻觉占绝对主导**：所有模型的 faithfulness 幻觉占比均超过 96%，远高于 factuality 和 logical。这与医学 VQA 场景特性一致——模型的主要问题是对放射科图像的视觉感知错误（误读病变、错误描述解剖结构），而非医学知识错误或逻辑推理错误
- **所有模型的 open HR 均高于 closed HR**：open 场景下模型需生成自由文本回答，暴露视觉感知缺陷的机会更多，幻觉率因此显著上升
- 医学 VQA 的 HR 整体高于 MathVista 的 Direct 模式（GPT-5.4-mini 33.26% vs 45.1%，但 Qwen 系列降幅明显），说明医学图像理解的难度对 MLLM 而言可能低于数学图文推理——GPT 的医学 HR 远低于其数学 HR，而 Qwen 系列的医学 HR 则显著高于其数学 HR
